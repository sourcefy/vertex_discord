## 🚀 Über den Bot

**Dein Bot Name** ist ein smarter Discord-Bot für Communitys, Teams und Creator.
Er kombiniert **schönes Design**, starke Performance und viele nützliche Funktionen in einem modernen Paket.

---

## ✨ Features

- **Admin**
  - Kick, Ban, Timeout, Warns
  - AutoMod
  - Rollen- und Channel-Management

- **AI**
  - Chat-Antworten
  - Text-Zusammenfassungen
  - Intelligente Hilfestellung
  - Smarte Server-Unterstützung

- **Economy**
  - Coins sammeln
  - Daily Rewards
  - Shop-System
  - Arbeiten, Casino, Bank

- **Fun**
  - Memes
  - Games
  - Roll, Coinflip, Random-Facts
  - Spaß-Commands

- **Leveling**
  - XP-System
  - Rank-Cards
  - Level-Up-Benachrichtigungen
  - Leaderboard

- **Setup**
  - Einfache Server-Konfiguration
  - Welcome- und Goodbye-System
  - Auto-Roles
  - Log-Channel Setup

- **Utility**
  - Ping
  - User-Info
  - Server-Info
  - Avatar
  - Help-Menü

## 📌 Commands

| Kategorie | Beispiele |
|---|---|
| Admin | `/ban`, `/kick`, `/timeout`, `/warn`, `/purge` |
| AI | `/chat`, `/ask`, `/summarize` |
| Economy | `/balance`, `/daily`, `/work`, `/shop`, `/pay` |
| Fun | `/meme`, `/joke`, `/8ball`, `/coinflip` |
| Leveling | `/rank`, `/leaderboard`, `/xp` |
| Setup | `/setup`, `/welcome`, `/autorole`, `/logs` |
| Utility | `/ping`, `/userinfo`, `/serverinfo`, `/avatar`, `/help` |

## 🛠️ Installation

```bash
git clone https://github.com/DEINNAME/DEINREPO.git
cd DEINREPO
npm install
npm run start
```

---

## ⚙️ Konfiguration

Erstelle eine `.env` Datei:

```env
BOT_TOKEN=dein_token
CLIENT_ID=deine_client_id
GUILD_ID=deine_server_id
DATABASE_URL=deine_db_url
OPENAI_API_KEY=dein_ai_key
```
